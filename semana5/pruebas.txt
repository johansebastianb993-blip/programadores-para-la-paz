1. Ruta: http://localhost:3000
   Resultado: Muestra el mensaje "Servidor activo".
   Descripción: Es la ruta raíz (/) del servidor. Confirma que el servidor está encendido y respondiendo correctamente a las solicitudes básicas.

2. Ruta: http://localhost:3000/saludo
   Resultado: Muestra el mensaje "Hola comunidad".
   Descripción: Es una ruta estática (/saludo) diseñada para enviar un saludo fijo predeterminado a los usuarios.

3. Ruta: http://localhost:3000/mensaje/juan
   Resultado: Muestra el mensaje "Hola juan".
   Descripción: Es una ruta dinámica (/mensaje/:nombre) que utiliza parámetros de ruta. El servidor captura el valor proporcionado en la URL (en este caso, "juan") mediante `req.params.nombre` y lo concatena dinámicamente en la respuesta.
